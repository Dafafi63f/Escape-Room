CUESTIONARIO MATCAD — Cómo jugar — v1.1.0
=========================================

Descarga solo el juego (sin el repo entero):
  https://github.com/Dafafi63f/Escape-Room/releases/download/juego/MATCAD_juego_portable.zip

1. Instala Python 3.10+ desde https://www.python.org/downloads/
   (marca "Add python.exe to PATH").
2. En la carpeta del zip descomprimido (o en la raíz del repositorio):
     pip install -r Juego\requirements.txt
   En Windows también puedes usar Jugar.bat del zip.
3. Arranca:
     python Juego\juego_grafico.py

Más ayuda: Juego\COMO_JUGAR.md
